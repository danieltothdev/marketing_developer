# Telepítés a site-2 (tdaimarketing.hu) projektbe

Ez a mappa egy **kész, másolható blogoldal** a site-2 HTML-struktúrájához.

## Fájlok

| Fájl | Hova másold a site-2 gyökerében |
|------|----------------------------------|
| `blog-konverziomeres-kkv-ajanlatkeres-2026.html` | gyökér, **ugyanoda**, ahol a többi `blog-*.html` van |
| `assets/blog-konverziomeres-kkv-ga4.png` | `assets/` |
| `BLOG-INDEX-SNIPPET.html` | illeszd be a `blog.html` kártyarács **tetejére** (első cikk) |
| `BLOG-SCHEMA-SNIPPET.json` | add hozzá a `blog.html` `Blog.blogPost` tömbhöz |

Éles URL: `https://tdaimarketing.hu/blog-konverziomeres-kkv-ajanlatkeres-2026`

## Lépések

1. Másold a HTML-t és a PNG-t a site-2-be.
2. Illeszd be a blogindex kártyát.
3. Add hozzá a slugot a sitemaphez.
4. Teszteld: [Rich Results](https://search.google.com/test/rich-results) + [schema.org validator](https://validator.schema.org/).
5. GSC: URL-ellenőrzés → indexelés kérése.

## Miért ez a téma?

A site-2-n van Ads vs Meta, landing, automatizáció és SEO/AEO — de **nincs önálló konverziómérés-útmutató**. Ez a hub összeköti a klasztert, és AEO-ra (FAQ + HowTo) is alkalmas.
